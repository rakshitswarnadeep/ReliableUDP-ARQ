# ReliableUDP-ARQ
Reliable Data Transfer over UDP using Python.
## Project
This project implements reliable file transfer over UDP using:
- Stop-and-Wait ARQ
- Go-Back-N ARQ
- Selective Repeat ARQ
## Features
- UDP-based communication
- Sequence numbers
- Checksums
- ACKs and retransmissions
- Channel error simulation
- File integrity verification
- Performance comparison of ARQ protocols
